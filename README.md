## How to Run the Programs

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the C++ file you want to execute.
4. Compile the program using:

```bash
g++ filename.cpp -o program
```

5. Run the compiled program on Windows:

```powershell
.\program.exe
```

Replace `filename.cpp` with the name of the program you want to run.

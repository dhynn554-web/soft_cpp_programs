# Student Marks Analyzer

## Project Overview

Student Marks Analyzer is a C++ mini project that calculates and analyzes students' marks and generates a performance report.

## Features

- Accepts the number of students (1–100).
- Validates student marks (0–100).
- Calculates total marks.
- Calculates average marks.
- Finds the highest mark.
- Finds the lowest mark.
- Counts passed and failed students.
- Allows the user to perform multiple analyses.
- Uses functions for modular programming.
- Uses dynamic memory allocation.

## Passing Criteria

A student is considered passed if their mark is **40 or above**.

## Technologies Used

- C++
- Arrays and Pointers
- Functions
- Loops and Conditional Statements
- Dynamic Memory Allocation
- Input and Output Operations

## How to Run

### 1. Clone or download this repository.

### 2. Compile the program

```bash
g++ student_marks_analyzer.cpp -o student_marks_analyzer
```

### 3. Run the program

**Windows:**

```powershell
.\student_marks_analyzer.exe
```
